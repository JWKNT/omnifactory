Feeding an Assembly Line from ME

Page 804 opens after page 286. It checks eleven Actually Additions Item Laser Relays, an Item Interface and a Laser Wrench, then pays an OmniQuarter. Page 531's mainframe already has nine different solid ingredients. The book recommends linking the single-stack input buses into a virtual inventory so ME can run different recipes on the same line.

The six corner and side piers leave the center of the first line open at y81, z−19. Place one relay directly below each input bus. The relays link in a chain with the Laser Wrench. Each sees every adjacent inventory. Put the Item Interface just beyond the first relay, where it touches exactly one relay. The book reports that letting a second relay touch the same interface creates a cycle that crashes the game. Keep the output bus on a separate return. Enable blocking mode on the ME Interface that supplies the Item Interface and test a single complete ingredient set before submitting a second. If a later recipe needs a permanent program circuit, reserve a bus for it.

JEI gives four Energy Laser Relays for four obsidian, two redstone blocks, two Restonia Crystals and one Advanced Coil. Three crafts cover all eleven buses. The Atomic Reconstructor converts energy relays into fluid relays and fluid relays into item relays. Process eleven through each step and save the spare energy relay. The viewer takes four Basic Coils, two redstone, two Restonia Crystals and a chest. The new Laser Wrench takes one Advanced Coil and two Enori Crystals. Budget twelve obsidian and six redstone blocks for the relay frames alone. Stage obsidian and coils while making the IV motors. As of 79h20m the deck and piers exist. The relays and line are still to be built.

JEI gives 1,000 mB lava per magma block in a chemical reactor, then one obsidian per bucket in a fluid solidifier. The thermal extruder also uses a bucket of water. Twelve magma blocks therefore cover the relay frames without another quarry trip. The unused MV reactor at (6,81,2) was empty and fully charged. Run a twelve-block obsidian batch with the block mold, then switch to the ball mold for the gases. The existing plastic and epoxy casters can keep their molds.
