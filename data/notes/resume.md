# Pick up in the void factory

The quest book has 49 unique completed quests. The void has a self-feeding Snad boiler, two turbines, a 2,501,024 EU CEF with a flux capacitor, and four powered LV machines. Start with void-stores.md for chests, furnace bank and stock tools, boiler-farm.md for the fuel farm, and macerator.md for the current iron order. The run remains in survival, Peaceful, with recording enabled.

The macerator received 32 iron ore. Finish that order while gathering a diamond for the lathe. The LV order planner reads actual JEI inputs and yields. lv-orders.md lists shared parts and the iron gallery. The next large build is the electric blast furnace. Old camp machine placements in earlier notes describe the first layout; void-steam.md and macerator.md give the installed locations.
