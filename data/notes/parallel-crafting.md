# A second independent crafting CPU

At 33h26m the network reported one idle CPU with 1,024 bytes. Several unrelated orders needed the same rubber sheets, copper wire, and wrought iron plates. The compressor, wiremill, furnace and HV assembler have separate ME interfaces already. A second CPU lets a supply order occupy one machine while another order uses the rest of the network. A co-processor helps execute steps within a job. A separate CPU accepts a second job.

The second 1k CPU is queued at (9,83,0), on the west side of the chemistry ME cable. It is separated from the first storage block at (9,82,9). Both the 1k and 4k take a Crafting Unit with four aluminium plates, two Calculation Processors, one Logic Processor and two fluix cables. The 1k component uses four glass, four red alloy plates and a basic-grade circuit. The current network has completed multiple full-stack wire orders on 1k, so a second independent 1k suits these jobs. Quest 110 was claimed on the first unit. Quest 109 explains how interfaces can stock items; quest 133 recommends stocking the Refined Circuits themselves as upstream supply improves.

scripts/parallel_cpu.py checks the real CPU list before enabling stock orders. It targets 32 rubber sheets, 32 single copper wires and 16 wrought plates in bounded batches. It leaves at least one CPU free and protects some raw material for other orders. Watch for two busy CPUs on different machines and two completed outputs. The orders are submitted at workshop visits. The dedicated polymer smelter needs its physical inlet as described in polymer-inlet.md to keep feeding simulations when the player is elsewhere. The second CPU and its overlap trial are pending.

The optional quest specifically called Keeping Stuff In Stock is page 97. It is unlocked and pays one quarter for holding an ME Storage Bus and a Crafting Card. Its description explains that a storage bus exposes an interface’s stock to recipes and that a crafting card asks the CPU for missing stock. It recommends simple recipes for that arrangement because large recursive jobs are recalculated. The storage bus in this instance takes an MV piston and an ME Interface. A Crafting Card takes a Basic Card and crafting table. The matter drawer controller at (14,80,10) already has real inputs from the chambers and would make good use of that bus after the quest check. A physical filtered inlet on the polymer smelter saves a CPU entirely. Quest 789 explains how the ordinary Item Filter sets a separate count for each entry on a Keep Exact arm.

The second CPU now has both calculation processors, the logic processor and its 1k ME Storage Component. The network compressor delivered four aluminium plates for the unit. All three existing item cells hold 63 distinct types each at most, and two have already reached that limit with several hundred spare bytes. Another 1k item cell adds the same 63 type slots as a 4k for less material. It needs four fine red alloy wires and four electrical steel plates for the housing plus a 1k component. There are no direct item cell quest rewards. scripts/item_cell.py will install one more disk at the chemistry build if at most sixteen type slots remain.
