# The first LV assembling machine

The first Primitive Processor was made from four basic circuits. Quest 76 paid an omniquarter and the MV Circuits milestone also completed. The finished processor and MV hull are in the void parts chest. Produce one more primitive processor and two more basic circuits for the robot arms. Two LV arms, two conveyors, a fresh LV hull, the two processors, and two tin cables make the assembler. Quests 516 and 517 detect the conveyor and arm before quest 72. The assembler opens a cheaper circuit family, machine controllers and ME conduits. The MV hull is reserved for later MV equipment.

After the first processor, the stock-adjusted order needed another 72 rubber, 44 iron ingots, 13 tin ingots, 20 paper, 18 glass panes, three wood slabs, four redstone and two charcoal dust. This estimate excludes machine and furnace inventories. Forty-two impure iron dust have already been divided evenly between the east and north furnaces, so most of the iron is covered once smelting finishes. The ten motors need 26 normal iron rods across this order after using the ones already in storage. Make rods at the lathe, where each ingot gives two. The remaining production includes 40 wrought ingots, 32 wrought plates and four steel rods. Count the machine outputs before buying more raw ore.

The working order command is scripts/lv_order.py with an item ID, --stock FILE and --carried. Generate FILE by running scripts/stores.py in the void. --stage fetches the required stocks through chest screens. --bench checks that only bench work remains and then sends the ordered recipes to the crafting table. The first primitive processor was built end to end this way, including tubes, cable insulation, resistors, boards and four basic circuits. Recompute from a fresh stock listing after any partial order.
